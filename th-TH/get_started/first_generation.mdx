---
title: First generation (หัวข้อหลักคงไว้เป็นภาษาอังกฤษ)
---

ส่วนนี้อธิบายกระบวนการ "first generation" — การสร้างผลลัพธ์เริ่มต้นจากการตั้งค่าพารามิเตอร์และรันเวิร์กโฟลว์ ในหน้านี้จะมีคำแนะนำทีละขั้นตอน ตัวอย่างการตั้งค่า และเคล็ดลับการปรับแต่งเพื่อให้ได้ผลลัพธ์ที่ต้องการ

การเตรียมตัวก่อนเริ่ม

- ตรวจสอบว่าคุณได้ติดตั้งและโหลดโมเดลที่ต้องการไว้ในโปรเจกต์แล้ว (ดูหน้าการติดตั้งสำหรับวิธีการติดตั้งโมเดล)
- เตรียมภาพอินพุตหรือพรอมต์ (prompt) ที่ต้องการใช้เป็นจุดเริ่มต้น
- ถ้าคุณใช้ GPU ให้ตรวจสอบไดรเวอร์และไลบรารีที่จำเป็น เช่น CUDA/cuDNN (ตามเอกสารการติดตั้ง)

ขั้นตอนหลัก (สรุป)

1. เปิดโปรเจกต์ ComfyUI และโหลดโมเดลที่ต้องการ
2. สร้างหรือเลือกเวิร์กโฟลว์ (workflow) ที่จะใช้สำหรับการสร้าง
3. ตั้งค่าพารามิเตอร์สำคัญ เช่น ขนาดภาพ (width/height), จำนวนขั้นตอน sampling (steps), ค่า seed (ถ้าต้องการความสามารถในการทำซ้ำ), และการตั้งค่า sampler
4. ปรับแต่ง input เช่น prompt, negative prompt, หรือภาพเริ่มต้น (เมื่อใช้ image-to-image)
5. รันเวิร์กโฟลว์และรอผลลัพธ์
6. ตรวจสอบผลลัพธ์ในหน้าผลลัพธ์ (preview) และบันทึกภาพที่พอใจ

เคล็ดลับและข้อควรระวัง

- หากต้องการผลลัพธ์ที่สามารถทำซ้ำได้ ให้ตั้งค่า seed คงที่ หากต้องการความหลากหลาย ให้ใช้ seed แบบสุ่ม
- เริ่มจากค่าพารามิเตอร์มาตรฐาน (เช่น steps 20–50) แล้วปรับเพิ่มหรือลดตามคุณภาพที่ต้องการ
- หากภาพมีนอยซ์หรือแปลก ให้ลองปรับ sampler หรือจำนวน steps ก่อนเปลี่ยน prompt มาก
- สำหรับโมเดลขนาดใหญ่และการสร้างภาพความละเอียดสูง ใช้ GPU และเพิ่มหน่วยความจำ (VRAM) หรือใช้การแบ่งงานเป็นพาร์ติชัน

ตัวอย่างสั้น ๆ (workflow)

- เลือกโมเดล > ตั้งค่า prompt และ negative prompt > ตั้งค่า steps และ seed > รัน > ตรวจสอบผลลัพธ์

หมายเหตุ: หัวข้อหลักและชื่อไฟล์ยังคงเป็นภาษาอังกฤษตามข้อกำหนด เพื่อให้ง่ายต่อการซิงค์กับระบบการแปลอัตโนมัติหรือ workflow อื่น ๆ
