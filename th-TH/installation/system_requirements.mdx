---
title: system_requirements (หัวข้อหลักคงไว้เป็นภาษาอังกฤษ)
---

หน้านี้สรุปความต้องการขั้นต่ำและคำแนะนำเกี่ยวกับฮาร์ดแวร์/ซอฟต์แวร์เพื่อเรียกใช้งาน ComfyUI ได้อย่างราบรื่น

ระบบปฏิบัติการ

- รองรับ: Windows, macOS และ Linux

หน่วยความจำ (RAM)

- ขั้นต่ำ: 8 GB (สำหรับงานพื้นฐาน)
- แนะนำ: 16 GB หรือมากกว่า หากต้องการรันโมเดลขนาดใหญ่หรือหลายเวิร์กโฟลว์พร้อมกัน

GPU (การ์ดกราฟิก)

- ไม่จำเป็นสำหรับการรันพื้นฐาน แต่แนะนำสำหรับงาน inference ที่ต้องการประสิทธิภาพสูง
- หากใช้ GPU: ตรวจสอบเวอร์ชันไดรเวอร์ CUDA/cuDNN ให้ตรงกับไลบรารีที่ใช้ (ตัวอย่างเช่น PyTorch/torchvision ที่รองรับ)

พื้นที่เก็บข้อมูล

- ควรมีพื้นที่ว่างเพียงพอสำหรับเก็บโมเดลและตัวอย่างภาพ (ขนาดโมเดลอาจตั้งแต่หลายร้อย MB จนถึงหลาย GB)

Python และไลบรารี

- Python 3.8+ (ตรวจสอบ README หรือตัวติดตั้งสำหรับเวอร์ชันที่แนะนำ)
- ไลบรารีหลักเช่น PyTorch ต้องติดตั้งเวอร์ชันที่รองรับ GPU หากต้องการใช้งาน GPU

คำแนะนำเพิ่มเติม

- หากไม่มี GPU ให้พิจารณาใช้เครื่องที่มี RAM และ CPU สูงขึ้น หรือใช้ instance บนคลาวด์สำหรับการทดลอง
- เปิดใช้งาน swap หรือเพิ่มหน่วยความจำเสมือนสำหรับงานที่กินหน่วยความจำมาก หากจำเป็น
- ดูหน้าการติดตั้ง (installation) สำหรับคำแนะนำการติดตั้งไดรเวอร์และการตั้งค่าสิ่งแวดล้อม

หมายเหตุ: ยังคงเก็บหัวข้อหลักเป็นภาษาอังกฤษเพื่อให้ง่ายต่อการอ้างอิงข้ามภาษาหรือกระบวนการซิงค์
